# 服务条款

**最后更新日期：2026年6月4日**

欢迎使用 SooAPI 服务！本服务条款（以下简称本条款）是您与 SooAPI 之间关于使用我们服务的法律协议。

## 1. 服务说明

### 1.1 服务内容

SooAPI 提供 AI 模型 API 中转服务，包括但不限于：
- 多种 AI 模型的统一接入接口
- API 调用管理和监控
- 额度管理和计费服务

### 1.2 服务变更

我们保留随时修改、暂停或终止服务的权利，恕不另行通知。对于重大变更，我们将通过邮件或站内通知告知您。

## 2. 账户管理

### 2.1 账户注册

- 您必须提供真实、准确的信息完成注册
- 您应对账户安全负责，不得与他人共享账户
- 如发现账户被盗用，应立即通知我们

### 2.2 账户使用

- 您的账户仅限个人使用，不得转让、出售或出租
- 您应对账户下的所有活动负责
- 我们有权拒绝或终止违反本条款的账户

## 3. 使用规范

### 3.1 您承诺不会

- 使用服务从事任何违法或侵权活动
- 尝试破解、攻击或破坏我们的系统
- 滥用 API 调用或进行恶意刷量
- 将服务用于任何可能损害他人权益的目的
- 未经授权访问他人数据或账户

### 3.2 您同意

- 遵守所有适用的法律法规
- 不干扰其他用户使用服务
- 及时支付服务费用
- 对使用服务的后果承担责任

## 4. 费用与支付

### 4.1 计费方式

- 我们采用预付费模式，您需要预先充值额度
- API 调用按实际使用量计费
- 不同模型有不同的计费标准

### 4.2 支付与退款

- 支持多种支付方式（支付宝、微信支付等）
- 充值成功后，额度立即到账
- 未使用的余额可申请退款，退款周期为 7-15 个工作日
- 因违规使用被终止服务的，余额不予退还

- 您通过 API 生成的内容归您所有

## 6. 服务质量与保障

### 6.1 服务可用性

- 我们致力于提供稳定可靠的服务
- 我们不保证服务不会中断或无错误
- 对于服务中断，我们将尽快修复并通知您

我们重视您的隐私保护，具体内容请参阅我们的 [隐私政策](/docs/policies/privacy)。

### 8.1 禁止行为

### 9.1 您可以
