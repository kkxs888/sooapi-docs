# 使用协议

**最后更新日期：2026年6月4日**

欢迎使用 SooAPI 平台服务！本使用协议（以下简称本协议）规定了您使用 SooAPI 平台服务的权利和义务。

## 1. 协议的接受

### 1.1 协议生效

- 当您注册、登录或使用 SooAPI 服务时，即表示您已阅读、理解并同意接受本协议
- 如您不同意本协议的任何条款，请立即停止使用我们的服务

### 1.2 协议修改

- 我们有权随时修改本协议
- 修改后的协议将在平台公布，继续使用服务即视为接受修改
- 如您不同意修改，可选择停止使用服务

## 2. 服务定义

### 2.1 服务范围

SooAPI 平台提供的 AI 模型 API 中转服务，包括：
- OpenAI、Claude、Gemini、DeepSeek 等多种 AI 模型的统一接入
- API 密钥管理和调用统计
- 额度充值和费用结算
- 技术文档和使用指南

### 2.2 服务限制

- 服务仅限合法合规用途
- 我们有权根据运营情况调整服务内容和价格
- 某些高级功能可能需要额外付费或满足特定条件

## 3. 用户资格

### 3.1 注册条件

- 您必须年满 18 周岁或具有完全民事行为能力
- 未成年人在监护人同意下可使用服务
- 您应提供真实、准确的注册信息

### 3.2 账户安全

- 您应妥善保管账户密码，不得泄露给他人
- 账户下的所有行为由您承担责任
- 发现账户被盗应立即通知我们

## 4. 用户权利与义务

### 4.1 您的权利

- 合法使用平台提供的所有服务
- 查询账户余额、使用记录等信息
- 对服务质量提出意见和建议
- 申请注销账户

### 4.2 您的义务

- 遵守本协议及相关法律法规
- 按时足额支付服务费用
- 不得从事违法、侵权或损害他人利益的活动
- 不得干扰平台正常运营

## 5. 平台权利与义务

### 5.1 我们的权利

- 制定和修改平台规则
- 对违规行为进行处罚
- 调整服务内容和价格
- 终止违规用户的服务

### 5.2 我们的义务

- 提供稳定可靠的服务
- 保护用户个人信息安全
- 及时处理用户反馈和投诉
- 明示收费标准和服务内容

## 6. 服务费用

### 6.1 收费标准

- 不同 AI 模型有不同的计费标准
- 收费标准以平台公布为准
- 我们有权根据成本变化调整价格

### 6.2 支付方式

- 支持支付宝、微信支付等方式
- 充值金额将转换为平台额度
- 额度不可转让、不可提现（符合退款条件的除外）

### 6.3 发票

- 可根据实际消费金额开具发票
- 开票申请请在消费后 30 天内提出

## 7. API 使用规范

### 7.1 合理使用

- 不得进行恶意刷量、攻击等行为
- 遵守各 AI 模型的使用限制
- 不得将 API 用于非法用途

### 7.2 内容责任

- 您对通过 API 生成的内容负责
- 不得生成违法、有害、侵权内容
- 如产生法律纠纷，由您自行承担

### 7.3 数据安全

- 您应妥善保管 API 密钥
- 密钥泄露应立即更换
- 因密钥泄露造成的损失由您承担

## 8. 知识产权

### 8.1 平台权利

- SooAPI 平台的商标、标识、界面设计等归我们所有
- 未经许可不得使用、复制、传播

### 8.2 用户权利

- 您通过 API 生成的内容归您所有
- 您应确保生成内容不侵犯他人知识产权

## 9. 隐私保护

我们重视您的隐私保护，具体内容请参阅我们的 [隐私政策](/docs/policies/privacy)。

## 10. 免责声明

### 10.1 服务中断

以下情况导致的服务中断，我们不承担责任：
- 系统维护升级
- 不可抗力（自然灾害、战争等）
- 第三方原因（网络故障、电力中断等）
- 上游 AI 服务商故障

### 10.2 内容免责

- 我们不对 AI 生成的内容负责
- 您应自行判断内容的准确性和合法性

### 10.3 损失限制

在法律允许的范围内，我们的赔偿责任仅限于您支付的服务费用。

## 11. 违规处理

### 11.1 违规行为

包括但不限于：
- 使用服务从事违法活动
- 恶意攻击、破坏系统
- 侵犯他人合法权益
- 散布违法、有害信息

### 11.2 处罚措施

- 警告提醒
- 限制功能使用
- 暂停或终止服务
- 扣除违规所得
- 追究法律责任

## 12. 服务终止

### 12.1 用户终止

- 您可随时申请注销账户
- 注销前请确保余额已处理完毕
- 注销后账户信息将被删除

### 12.2 平台终止

出现以下情况，我们有权终止服务：
- 您严重违反本协议
- 您的账户存在重大安全风险
- 法律法规要求
- 平台停止运营

## 13. 争议解决

### 13.1 协商优先

双方应通过友好协商解决争议。

### 13.2 诉讼管辖

协商不成的，可向我们所在地有管辖权的人民法院提起诉讼。

## 14. 其他条款

### 14.1 通知送达

- 平台公告视为有效通知
- 重要通知将通过邮件或站内信发送

### 14.2 条款独立性

如本协议任何条款被认定无效，不影响其他条款的效力。
